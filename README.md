# Lithium-Ion Battery Capacity Degradation Prediction

An end-to-end data science pipeline for estimating Lithium-ion battery capacity degradation (State of Health / SOH) using feature engineering, standardized preprocessing, and competitive regressive modeling (*Gradient Boosting*, *Random Forest*, and *LSTM*).

This project benchmarks traditional ensemble methods against deep temporal learning architectures on NASA cycle-level summary battery datasets, demonstrating the superior performance of tree-based sequential boosting for tabular health indicator features.

---

## 📌 Key Benchmarking Results

The dataset contains **1,415 cycle records** evaluated on an **80:20 Train-Test split** (1,132 training samples, 283 testing samples).

| Model Architecture | RMSE (Ah) | MAE (Ah) | $R^2$ Score | Performance Summary |
| :--- | :---: | :---: | :---: | :--- |
| **Gradient Boosting Regressor** | **0.0955** | **0.0475** | **0.9129** | **Best Performance** (Lowest error & highest precision) |
| **Random Forest Regressor** | 0.1143 | 0.0408 | 0.8752 | Strong baseline, slight smoothing on extreme values |
| **LSTM Deep Learning** | 0.2160 | 0.1154 | 0.5543 | Underperformed due to discrete tabular cycle-level scope |

> **Key Finding**: *Gradient Boosting Regressor* achieves an **$R^2$ score of 91.29%** with an average error of ~0.0475 Ah (~2.5% relative error). Sequential decision tree boosting excels at capturing non-linear capacity fade curves driven by rolling temporal health indicators (`vol_rolling_mean` & `temp_rolling_mean`).
